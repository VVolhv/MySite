Универсальная CRM

CRM for All

Локальная CRM-система, подходящая для любого вида бизнеса. Работает полностью офлайн: встроенный PHP и SQLite, без серверов и подписок. Задачи, клиенты, почта, модули и гибкая система лицензий.

  • Подходит для любого бизнеса
  • Встроенный PHP-runtime — ставится в 1 клик
  • SQLite: база в одном файле
  • Встроенная почта с 3-колоночным интерфейсом
  • Модульная архитектура (loader.php)
  • Схема лицензий и платежей

Визуальный редактор задач

ViewNodeLab

GUI для визуального программирования n8n-нод на PyQt6. Перетаскивай ноды, соединяй их и запускай автоматизации — сотни готовых интеграций: Telegram, Slack, Notion, OpenAI, Stripe и другие.

  • Визуальный node-редактор на canvas
  • Движок исполнения потоков (engine.py)
  • Сотни n8n-нод интеграций
  • HTTP Request, Webhook, триггеры
  • GitLab Trigger нода
  • Декларативный формат нод (.node.json)

Философия простоты

Я верю, что мощные инструменты не обязаны быть облачными и дорогими. CRM for All ставится одной кнопкой и живёт в одном файле базы — владелец бизнеса держит свои данные под рукой.

ViewNodeLab превращает интеграцию сервисов в игру: собрал ноды, соединил стрелками — и рабочая автоматизация готова.

$ pip install viewnode-lab
→ Загрузка нод... ✓ 400+ интеграций

$ CRM-for-All --start
→ PHP runtime встроен... ✓
→ SQLite подключена ... ✓
Готово. Бизнес работает.
