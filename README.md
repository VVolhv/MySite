# Мои Проекты — CRM for All & ViewNodeLab

Современный сайт-презентация двух проектов:

- **CRM for All** — универсальная локальная CRM (PHP + SQLite), подходящая для любого вида бизнеса
- **ViewNodeLab** — визуальный редактор n8n-нод на PyQt6 с сотнями интеграций

Один автономный файл `index.html` — просто откройте его в браузере.

## Технологии

- GSAP 3 + ScrollTrigger — анимации и scroll-эффекты
- Lenis — плавный скролл
- Canvas-частицы, магнитные кнопки, 3D-tilt, glassmorphism
- Шрифты: Inter, Unbounded

## Запуск

```bash
# просто откройте index.html
start index.html
```

Или поднимите локальный сервер:

```bash
python -m http.server 8000
# → http://localhost:8000
```
